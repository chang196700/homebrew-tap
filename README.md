# Chang196700 Tap

## How do I install these formulae?

`brew install chang196700/tap/<formula>`

Or `brew tap chang196700/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "chang196700/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
